## IX 专线到底是什么？和 IEPL、IPLC 差在哪

IX 指的是互联网交换中心（Internet Exchange Point）。传统专线，不管 IEPL 还是 IPLC，本质上都是“两点之间拉一根物理线”——广州到香港、上海到东京，一条电路点对点直连。IX 专线不是这样，它是“一点接入、经交换中心中转”：服务商在交换中心侧接入，用户的流量通过云厂商内网进入专线网络，再从海外出口出去。

Mkcloud 的知识库对自家的 IX 产品有明确说明：它是“通过支持云厂网络接入的出海 VPS”，每台机器分配 1 个独立入口 IP 和 1 个独立出口 IP，用户连入口后在 VPS 里跑业务，流量自动从出口发出。它不是你自己的 IXP 接入端口，零售用户也不需要自己的 ASN。

三种线路的核心差异可以列成一张表：

| 维度 | IX 专线 | IEPL / IPLC |
| --- | --- | --- |
| 接入方式 | 经云厂内网/交换中心接入，需要前置云机 | 点对点物理电路，绑定省份直连入口 |
| 入口暴露 | 入口在交换网络内网，不直接暴露公网 | 公网入口 IP |
| 省份限制 | 不限连入省份 | 绑定一个省份（可自行切换） |
| 额外成本 | 需要自备符合范围的云厂前置机 | 无前置，套餐价即全部 |
| 典型端内延迟（Mkcloud 数据） | 深港 1~2ms、沪港 21ms | 广港 1~2ms、沪港 21ms、沪日 25~28ms |

一句话概括：IX 用“自备云厂前置”换来了不限省份的灵活性和相对低一些的价格；传统直连则省事，开机就能连，但要绑定省份。

## Mkcloud 的 IX 专线交付形态：买的是 VPS，不是裸专线

这点在下单前必须搞清楚。Mkcloud 交付的是云服务器（VPS），不是给你一根可以自己接办公室的裸线路。实际使用流程是：

1. 准备一台在支持范围内的云厂机器（前置）；
2. 通过前置云机连接 Mkcloud 的 IX 入口地址；
3. 在 IX VPS 内运行业务程序，访问海外目标时流量从出口 IP 发出。

出口只负责向外访问，不支持外部连入。也就是说，它不能用来做公开网站、支付回调、邮件接收或游戏服务端。如果你需要的是一台能被外界访问的服务器，这个方向的产品从架构上就不满足。

另外两条硬性规则写在购物车里：所有产品需中国身份实名，禁止机场、回国等违法用途；直连类产品采用省级白名单，IX 类虽然不限省份，但连接必须来自支持范围内的云厂网络，普通家庭宽带和任意 BGP 主机不能直连。

前置成本有多重要？上面提到的评测博主给了一组实际数字：他用火山引擎 ECS 做前置，2G 带宽的机器约 550 元/年，共享流量包约 437 元/TB/年（按量计费约合 0.8 元/GB）。同时他指出，阿里云、腾讯云的轻量实例虽然便宜、标称 200M 带宽，但带宽没有强保证，已有实例被实际限速到 20M 甚至 1M 的情况。换句话说，IX 套餐标价之外，前置的稳定性和流量费用才是长期使用的真实成本。

官方知识库的说法一致：评估 IX 要“合计 VPS、前置、流量和管理费用”，已有合适的云资源可以摊薄成本，但不能只看 IX 套餐单价。

## 共享和独享怎么选

Mkcloud 的每台 VPS 都分配 1 个独立入口 IP 和 1 个独立出口 IP，共享和独享的区别不在 IP，而在带宽模式：

- **共享（流量计费）**：峰值带宽加月流量。流量按上行加下行双向统计，超量后暂停，可以自助购买流量重置或提交工单补差价升级。峰值带宽不保证持续跑满。
- **独享（带宽计费）**：带宽独占、不限流量，适合持续传输、多任务并发的场景。独享带宽档位覆盖 5M 到 5G。

判断方法不复杂：你的业务是“每天集中上传几波文件、查后台”，共享款按月流量算账更划算；如果是长时间持续传输、直播推流这类对持续速率敏感的任务，再考虑独享。以官方给的沪港入门套餐做参照，共享款 288 元/月（200M 峰值、1024GB 流量）和独享款 388 元/月（5Mbps、不限流量）对应的是两种完全不同的计费资源，200M 和 5M 这两个数字不能直接比大小。

## 什么人适合买，什么人不适合

基于已核验的配置、价格和限制，IX 专线的产品形态决定了它的适用面：

**适合的情况**：业务已经在阿里云、腾讯云、华为云等云上，正好有符合接入范围的云机做前置；需要操作海外店铺后台、调用授权 API、上传素材或做日区/美区客户端测试；希望入口不暴露公网、业务环境相对干净；需要在多个省份使用而不想被省份绑定限制。

**不适合的情况**：纯个人轻量上网需求，Mkcloud 起步价 158 元/月再加上前置成本，明显超出必要开销；需要公开建站、做游戏服务端或接收支付回调的业务，出口不支持入站，架构上就走不通；任何想绕过实名或用于合规范围之外用途的需求，平台有省级白名单和人工审核，不要抱侥幸心理。

第三方评测的态度也比较一致：有测评认为 Mkcloud 的定位是“给有真实业务需求的用户提供稳定的国际专线”，最便宜的套餐对只是偶尔需要境外网络的个人用户来说偏重；独立站和跨境电商场景则被普遍认为对得起价格。这些是别人的使用判断，参考即可，关键是把前面说的接入条件和总成本算清楚。

- **IP**：出口是服务器 IP，不保证原生、住宅或流媒体解锁，独享 IP 也不保证平台账号永不被限制。
- **流量**：计量型套餐按上下行双向合计，档位从 1TB 一直到 300TB。

## 常见问题

**IX 专线需要自己买云服务器做前置，是不是很麻烦？**

确实比直连款多一步，这也是 IX 便宜的核心原因——接入段由用户自备。如果你手上本来就有阿里云或腾讯云的机器，麻烦程度有限；从零开始的话，要把前置机租金和流量费算进月度成本再和直连款比较。

**深港、沪港、沪日、沪美，第一次买选哪个？**

按业务目标定：目标是香港就深港或沪港（深港延迟更低但要求华南云厂前置，沪港适合上海及周边），做日区业务选沪日，美区业务选沪美。先用小流量档位测一两周代表性任务，再决定是否升级，这比任何参数对比都可靠。

**端内 1~2ms 延迟意味着我访问网站就是 1~2ms 吗？**

不是。1~2ms 只是深圳到香港那段专线内部的参考值，你的完整路径是“本地到前置、前置到入口、出口到目标”，三段加起来才是真实体感。官方在产品总览里反复强调这一点，评测博主也持相同口径。

**能用来做机场或给多人共享吗？**

不能。平台全线产品需实名、限正规用途，明确禁止机场、回国等用途，并有白名单和人工审核机制。这条线不要碰。
